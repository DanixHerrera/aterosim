En este proyecto se desarrolla una simulación interactiva en 2D basada en agentes 2D de un corte longitudinal de una arteria para visualizar cómo se desarrolla una aterosclerosis debido al aumento del colesterol. En la arteria circulan partículas de LDL (colesterol malo), HDL (colesterol bueno) y oxidantes. Donde si está dañado o rasgado el endotelio, que es una capa fina que recubre la superficie interior de las arterias, venas y capilares, el LDL entra, se oxida y atrae macrófagos, células grandes del sistema inmunológico, que consumen los LDL y eso hace que se forme una placa de células espumosas que se va acumulando y estrechando las paredes de la arteria. Esto hace que la circulación de la sangre se dificulte.
